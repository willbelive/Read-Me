# Beat Claude

### The hiring challenge for AI-native professionals

We’re looking for strategists who can think better than AI.

## How It Works

* Pick a challenge from /challenges
* Read the brief
* Submit your answer
* We compare it to Claude’s answer through a blind review
* If you beat Claude → we want to talk

## Why This Exists

AI can already do 80% of knowledge work. The real value now comes from the remaining 20%: creative leaps, pattern recognition, strategic judgment, and the ability to operate under uncertainty.

If someone can’t outperform Claude on a real strategy problem, they’re competing with a commodity tool. We’re looking for people who make AI outputs feel average.

## The Rules

Use whatever tools you want — AI, research, collaborators, anything.

The baseline response was generated by Claude using the exact same brief you’re seeing. If you simply run the prompt through an AI model, you’ll likely produce a similar answer. That results in a tie. Ties don’t move forward.

To outperform Claude, you need to contribute something AI alone can’t generate: insight, originality, judgment, or asymmetric thinking.

### Submission Guidelines

* Estimated time: 1–2 hours per challenge
* Maximum length: 4 pages
* We’re evaluating judgment, prioritization, and strategic thinking — not endurance.
